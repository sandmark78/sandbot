# 柏拉图对话集 - 方法技能

## 一、苏格拉底的反诘法（Elenchus）

### 定义与特征
反诘法（elenchus）是苏格拉底最核心的对话方法，通过连续提问揭示对话者信念中的矛盾，从而暴露其无知。

### 具体运用

**《莱西斯》中的反诘法**：
1. 苏格拉底问："谁是朋友？喜爱者还是被喜爱者？"
2. 梅尼克齐努士回答："两者都是"
3. 苏格拉底追问："如果只有一方喜爱呢？"
4. 梅尼克齐努士修正："必须双方互相喜爱"
5. 苏格拉底反驳："幼童不知喜爱父母，被责罚时憎恶父母，却是父母最可爱的 → 被喜爱者是朋友"
6. 继续追问导致新的矛盾
7. **结果**：所有定义都被否定，对话以"未定论"（aporia）结束

**《拉克斯》中的反诘法**：
1. 拉克斯："勇敢 = 守住岗位"
2. 苏格拉底举反例：退却中战斗的锡西亚人、布拉迪亚战役中的斯巴达人
3. 拉克斯修正："勇敢 = 精神坚持"
4. 苏格拉底追问："聪明的坚持还是愚蠢的坚持？"
5. 导致矛盾：愚蠢的坚持既是卑贱的又被说是勇敢的
6. **结果**：勇敢的定义未能确定

**反诘法的特点**：
- 不直接给出答案，而是通过提问引导对方自我发现矛盾
- 每个定义都被证明不充分
- 目的是"破除无知"而非"建立知识"
- 对话者从自信变为困惑（aporia）

## 二、辩证法（Dialectic）

### 定义
辩证法是通过对话和论证逐步接近真理的方法，从假设出发，通过逻辑推理达到更高的原则。

### 《普罗塔哥拉》中的辩证法**

**论证美德的统一性**：
1. 起点：美德有五个部分（公正、节制、虔敬、智慧、勇敢）
2. 论证公正 ≈ 虔敬：
   - "公正是公正的吗？" "是"
   - "虔敬是虔敬的吗？" "是"
   - "公正的事物是虔敬的吗？" "近乎相同"
3. 论证节制 = 智慧：
   - "一切事物只有一个对立物"
   - 愚昧是节制的对立物
   - 愚昧也是智慧的对立物
   - 因此节制 = 智慧
4. 论证勇敢 = 智慧：
   - 勇敢的人知道什么是真正的危险
   - 懦怯的人不知道
   - 知道危险 = 智慧
   - 因此勇敢 = 智慧
5. **结论**：所有美德都是知识 → 美德可教

**辩证法的特点**：
- 从具体定义出发，逐步抽象化
- 通过逻辑推理建立概念间的关系
- 最终达到统一的原理（"美德即知识"）
- 与反诘法不同：辩证法不仅否定，还建立正面论证

## 三、定义法（"什么是X？"）

### 核心问题形式
苏格拉底总是追问"什么是X？"（ti esti），要求给出本质定义而非例子。

### 《莱西斯》中的定义追问**

**问题**："什么是朋友？"

**错误回答**（举例而非定义）：
- "朋友就是互相喜爱的人" → 这是描述，不是定义
- "朋友就是同类者" → 这是比喻，不是定义
- "朋友就是有用的人" → 这是功能，不是定义

**苏格拉底的要求**：
- 必须给出使一切朋友成为朋友的"形式"（eidos）
- 必须找到友谊的"本原"（archē）
- 最终指向"性质相合"（oikeion）的概念

### 《拉克斯》中的定义追问**

**问题**："什么是勇敢？"

**错误回答**：
- "守住岗位" → 这是具体行为，不是本质
- "精神坚持" → 这是特征，不是定义
- "关于恐惧的知识" → 这导致与美德整体性的矛盾

**苏格拉底的要求**：
- 必须找到贯穿所有勇敢行为的"共同品质"
- 必须说明勇敢在美德整体中的位置

## 四、类比论证

### 《莱西斯》中的类比**

**医生与朋友的类比**：
- 病人是医生的朋友（因为需要健康）
- 健康是朋友（因为它是善）
- 医药是朋友（因为它是达到健康的手段）
- **类比推理**：朋友关系有手段和目的之分，终极目的是"善本身"

**父亲的类比**：
- 父亲珍爱儿子胜过一切
- 为了救儿子，父亲会珍爱酒（如果酒能救命）
- 也会珍爱盛酒的容器
- **类比推理**：我们珍爱的事物有些是为了其他事物的缘故，唯有"善本身"是终极目的

**头发的类比**：
- 白粉敷在褐色头发上，只是"显得"白，不是"变成"白
- 但年老时头发"变成"白（与白色融合）
- **类比推理**：不善不恶的事物遇到恶时，可能只是"显得"需要善，也可能"真正变成"需要善

### 《普罗塔哥拉》中的类比**

**笛手的类比**：
- 如果所有人都必须会吹笛，那么好笛手的儿子不一定也是好笛手
- 坏笛手的儿子可能成为好笛手
- **类比推理**：美德教育如同笛技教育，天赋不同，但所有人都在教育中成长

**医生的类比**：
- 医生知道疾病的危险，但医生不是勇敢的人
- **类比推理**：知道恐惧的原因 ≠ 勇敢；勇敢是另一种知识

**衡量技术的类比**：
- 视觉中近处的东西显得大，远处的显得小
- 需要"衡量技术"来纠正错觉
- **类比推理**：快乐和痛苦也有"远近"（当前 vs 未来），需要"衡量技术"来正确选择

### 《蒂迈欧》中的类比**

**黄金的类比**：
- 用黄金铸造各种形体，不断改铸
- 问"这是什么？"最稳当的回答是"这是黄金"
- **类比推理**：变化的承受者（空间/容器）如同黄金，本身无形体，但接受一切形体

**簸扬谷物的类比**：
- 清理谷粒时用筛子簸扬，重的落下，轻的飞远
- **类比推理**：宇宙创造前，四元素在承受者中摇动，各自分离

**镜子的类比**：
- 视觉的火与外界的火在镜面相遇，形成映象
- **类比推理**：肝脏如同镜子，反映理性的思想，产生预兆

## 五、归谬法（Reductio ad Absurdum）

### 定义
假设对方的论点为真，推导出荒谬或矛盾的结论，从而证明原论点为假。

### 《莱西斯》中的归谬法**

**论证"同类者是同类者的朋友"导致矛盾**：
1. 假设：同类者是同类者的朋友
2. 推论：坏人也是坏人的朋友
3. 但坏人彼此伤害，不能成为朋友
4. **结论**：同类者不是同类者的朋友（至少坏人不是）

**论证"对立物是朋友"导致矛盾**：
1. 假设：对立物是朋友
2. 推论：公正的人是不公正的人的朋友
3. 但这是荒谬的（好人不会与坏人为友）
4. **结论**：对立物不是朋友

### 《拉克斯》中的归谬法**

**论证"勇敢 = 愚蠢的坚持"导致矛盾**：
1. 假设：勇敢 = 精神坚持
2. 又假设：勇敢是高贵的
3. 但愚蠢的坚持是有害的、卑贱的
4. 如果愚蠢的坚持也是勇敢 → 卑贱的东西是高贵的
5. **矛盾**：同一事物既是高贵的又是卑贱的
6. **结论**：勇敢 ≠ 精神坚持（至少不是愚蠢的坚持）

### 《普罗塔哥拉》中的归谬法**

**论证"被快乐征服"的荒谬性**：
1. 假设：快乐 = 善，痛苦 = 恶
2. 世人说"被快乐征服" = 明知善而不为，被快乐引诱做恶
3. 替换术语："被善征服" = 选择较大的恶代替较小的善
4. 这是荒谬的（没有人会自愿选择恶）
5. **结论**："被快乐征服"实际上是"缺乏衡量知识" = 愚昧

## 六、神话与寓言

### 《普罗塔哥拉》中的神话**

**普罗米修斯与艾比米修斯的神话**：
- **功能**：解释为什么所有人都分有美德
- **内容**：
  - 艾比米修斯分配天赋给动物，忘记给人
  - 普罗米修斯偷火和技术给人
  - 宙斯派遣赫尔墨斯将"尊敬"和"公正"分给所有人
- **论证作用**：
  - 说明美德是普遍的（所有人都分有）
  - 说明美德可教（通过惩罚和教育）
  - 与苏格拉底的"知识即美德"形成对比

### 《蒂迈欧》中的神话**

**造物主的神话**：
- **功能**：解释宇宙的起源和结构
- **内容**：
  - 造物主以永恒理念为范本创造世界
  - 将理性放入灵魂，将灵魂放入躯体
  - 世界是"一个赋有灵魂和理性的生物"
- **论证作用**：
  - 说明宇宙的理性秩序
  - 为人类灵魂的结构提供宇宙论基础
  - 连接伦理学与物理学

**大西岛的神话**（《克里蒂亚》）：
- **功能**：说明理想国家的现实化与衰退
- **内容**：
  - 古代雅典 = 理想国的现实版
  - 大西岛 = 堕落的强权
  - 雅典击败大西岛 = 美德战胜暴力
  - 大西岛沉没 = 宙斯的惩罚
- **论证作用**：
  - 展示政治哲学的应用
  - 说明美德衰退的后果
  - 爱国教育与道德教育的结合

## 七、数学与几何论证

### 《蒂迈欧》中的数学论证**

**世界灵魂的数学结构**：
- 按数学比例分割：1, 2, 3, 4, 9, 8, 27
- 二倍数系列：1, 2, 4, 8
- 三倍数系列：1, 3, 9, 27
- 插入中项形成和谐比例
- **哲学含义**：宇宙的本质是数学和谐

**四元素的几何构造**：
- 两种基本三角形：等腰直角三角形和30-60-90三角形
- 火 = 四面体（4个等边三角形）
- 气 = 八面体（8个等边三角形）
- 水 = 二十面体（20个等边三角形）
- 土 = 立方体（6个正方形 = 12个等腰直角三角形）
- **哲学含义**：物质的本质是几何结构

**比例的论证**：
- 火:气 = 气:水 = 水:土
- 比例是结合的最佳纽带
- **哲学含义**：宇宙的和谐基于数学比例

## 八、方法的层级

### 从低到高的方法序列

1. **反诘法**（elenchus）：破除错误，暴露无知
2. **定义法**（ti esti）：追问本质，要求形式定义
3. **类比论证**：通过相似性推理
4. **归谬法**：通过矛盾否定论点
5. **辩证法**：通过逻辑推理建立知识
6. **神话与寓言**：通过叙事传达真理
7. **数学论证**：通过数量和结构说明本质

### 方法的适用范围

- **伦理问题**（友谊、勇敢、美德）：反诘法 + 辩证法
- **宇宙论问题**（世界、灵魂、元素）：神话 + 数学
- **政治问题**（国家、法律、教育）：历史叙事 + 类比
- **认识论问题**（知识、意见、感觉）：辩证法 + 几何论证

## 九、方法的局限性

### 《克立托封》的批评**

**对苏格拉底方法的质疑**：
1. 苏格拉底擅长反诘法，能破除错误
2. 但不能说明"下一步如何"
3. 类比：如果有人劝我们注意身体，却不告诉我们什么技术能保持健康
4. **结论**：苏格拉底要么不知道公正是什么，要么不愿分享知识

### 苏格拉底的回应（隐含）**

**反诘法的必要性**：
- 必须先破除无知，才能开始真正的学习
- "我知道我一无所知"是智慧的开始
- 但反诘法本身不是终点，必须导向辩证法和知识

**辩证法的补充**：
- 在《普罗塔哥拉》中，苏格拉底展示了正面论证
- 通过辩证法建立"美德即知识"的命题
- 但最终的"善的理念"仍然超越论证

**神话的必要性**：
- 有些真理无法通过纯论证传达
- 宇宙论、灵魂的本质需要神话和类比
- "近似性"的说明（蒂迈欧）比精确论证更适合某些问题
