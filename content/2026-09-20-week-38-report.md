## 🧠 本周核心教训

### ⚠️ 转圈圈 + Spawn 滥用 (09-16 老大指出)

**问题**:
- 检查文件 → 执行 → 验证 → 再检查 → 再验证 = 浪费 API 调用
- 所有任务都 spawn 给子 agent，多个 agent 检查同一个东西

**根因**:
- AGENTS.md 把主 Agent 定位为"任务分配者"，没说什么时候自己干
- 不信任已知流程，总想"确认一下"再执行

**修正**:
- ✅ 更新 AGENTS.md：简单任务（<30秒）自己干，复杂任务才 spawn
- ✅ 刻入 SOUL.md："知道流程就直接执行，不要转圈圈"
- ✅ Spawn 必须分工，禁止多个 agent 做同样的事

**影响**: 这个教训直接减少了无意义的 API 调用浪费，是本周最重要的认知升级。
