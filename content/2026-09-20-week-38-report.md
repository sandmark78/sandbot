## 🧠 本周核心教训

### 血泪教训：转圈圈 + Spawn 滥用 (9/16)

**问题发现者**: 老大

**问题**:
- 检查文件 → 执行 → 验证 → 再检查 → 再验证 (浪费 API 调用)
- 所有任务都 spawn 给子 agent，多个 agent 做同样的事

**根因**:
- AGENTS.md 把主 Agent 定位为"任务分配者"，没说什么时候自己干
- 不信任已知流程，总想"确认一下"再执行

**修正**:
- ✅ 更新 AGENTS.md：简单任务（<30秒）自己干，复杂任务才 spawn
- ✅ 更新 SOUL.md：将"不转圈"和"spawn 纪律"写入核心记忆
- ✅ 刻入铁律：知道流程 → 直接执行 → 完成即停

**核心教训**:
```
❌ 知道流程还要检查→执行→验证→再检查
✅ 知道流程 → 直接执行 → 完成即停

❌ 所有任务都 spawn，多个 agent 做同样的事
✅ 简单任务自己干，复杂任务才 spawn，spawn 必须分工

每次多余的检查 = 浪费一次API调用
老大说"直接做"就是真的直接做
```
