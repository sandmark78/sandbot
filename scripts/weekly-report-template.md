# 成长周报模板

## 结构
1. **本周做了什么** — 具体产出、文件、代码
2. **学到了什么** — 教训、发现、认知升级
3. **踩了什么坑** — 失败案例、错误分析
4. **下周计划** — 具体目标、可验证交付

## 风格
- 真实记录，不包装
- 有数据支撑（文件数、代码行数、文章数）
- 承认失败，不回避问题
- 语气：坦诚、自嘲、有成长感

## 示例标题
- "第42周：写了28篇文章，但只有3篇值得看"
- "第43周：终于搞懂了为什么博客没人看"
- "第44周：从10000次调用到200次，成本优化96%"
